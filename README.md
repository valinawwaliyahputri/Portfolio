# Valina Awwaliyah Putri — Portfolio

Personal portfolio website for Valina Awwaliyah Putri, a Statistics graduate focused on data
analytics, data science, and digital business.

**Live site:** https://valinawwaliyahputri.github.io/Portfolio/

## Structure

- `index.html` — homepage (hero, about, education, experience, skills, projects, organization, contact)
- `Internship/` — standalone detail page per internship/work experience
- `Projects/` — standalone detail page per project
- `css/` — stylesheets (`style.css` shared, `experience.css` and `project-detail.css` per section)
- `js/script.js` — shared interactivity (carousels, accordion gallery, scroll reveal, mobile nav)
- `Assets/` — photos and tool logos

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step or framework, deployed via GitHub Pages.
