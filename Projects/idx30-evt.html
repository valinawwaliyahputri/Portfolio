Deteksi Outlier Saham IDX30

Project of Intern at Otoritas Jasa Keuangan · Jan 2025

Applied Extreme Value Theory (EVT) and multivariate control charts to detect anomalies in stock return portfolios, demonstrating strong statistical modeling and risk analytics skills.

✦ Tentang Project

Ringkasan

Dikerjakan selama masa magang di Otoritas Jasa Keuangan, proyek ini menerapkan Extreme Value Theory (EVT) dan grafik kendali multivariat untuk mendeteksi anomali pada return saham dalam portofolio IDX30. Pendekatan ini menunjukkan kemampuan pemodelan statistik dan analitik risiko yang kuat dalam konteks pengawasan sektor keuangan.

✦ Tools & Stack

Python

01

Kumpulkan & Siapkan Data

Mengumpulkan data return saham IDX30 untuk periode yang dianalisis.

02

Eksplorasi & Analisis

Menerapkan Extreme Value Theory untuk mengidentifikasi nilai ekstrem.

03

Bangun Grafik Kendali

Menyusun grafik kendali multivariat untuk mendeteksi anomali portofolio.

04

Sampaikan Hasil

Merangkum temuan anomali sebagai insight analitik risiko.
