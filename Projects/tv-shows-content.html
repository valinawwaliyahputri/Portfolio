✦ About the Project

Summary

Built for SSF (Sebelas Maret Statistics Fair) UNS 2024, this project explored a TV shows database to understand content performance patterns. The findings were translated into an interactive dashboard mapping ratings, genres, and viewership distribution to support content recommendations and programming strategy.
