Klasifikasi Tumor Otak dengan CNN

Final Project · Introduction to Data Science · Jun 2024

Brain tumor classification model using transfer learning with Convolutional Neural Networks (CNN) to support medical image analysis and diagnostic decision-making.

✦ Tentang Project

Ringkasan

Sebagai tugas akhir mata kuliah Introduction to Data Science, proyek ini mengembangkan model klasifikasi tumor otak menggunakan transfer learning dengan Convolutional Neural Network (CNN). Model ini dirancang untuk mendukung analisis citra medis dan membantu proses pengambilan keputusan diagnostik.

✦ Tools & Stack

Python

✦ Proses Pengerjaan

01

Kumpulkan & Siapkan Data

Menyiapkan dan melakukan preprocessing pada dataset citra MRI tumor otak.

02

Bangun Model CNN

Menerapkan transfer learning dengan arsitektur CNN untuk klasifikasi citra.

03

Latih & Evaluasi

Melatih model dan mengevaluasi akurasi klasifikasinya.

04

Sampaikan Hasil

Merangkum performa model sebagai dukungan analisis citra medis.
