✦ Tentang Project

Ringkasan

Sebagai tugas akhir mata kuliah Statistical Machine Learning, proyek ini membangun pipeline machine learning end-to-end untuk stratifikasi risiko penyakit jantung dan estimasi premi asuransi. Alur kerja mencakup preprocessing data medis dunia nyata, pemodelan klasifikasi, evaluasi performa model, hingga penerapan hasil ke dalam dashboard interaktif untuk mendukung pengambilan keputusan (decision support system).

01

Kumpulkan & Siapkan Data

Melakukan preprocessing pada dataset medis dunia nyata terkait risiko jantung.

Membangun dan melatih model machine learning untuk klasifikasi risiko.

03

Mengevaluasi performa model untuk memastikan akurasi dan keandalan hasil.

04

Deploy & Sampaikan

Menerapkan model ke dashboard Streamlit sebagai alat pendukung keputusan.
