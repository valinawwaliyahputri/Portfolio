✦ About the Project

Summary

As the final project for Statistical Machine Learning, this project built an end-to-end machine learning pipeline for heart disease risk stratification and insurance premium estimation. The workflow covered real-world medical data preprocessing, classification modeling, model performance evaluation, and deployment into an interactive dashboard to support decision-making (decision support system).
