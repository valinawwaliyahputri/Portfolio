✦ About the Project

Summary

Built as part of the UGM Community Service Program (KKN PPM) Period 2 2025 with Tim Swadarma Senduro, this project developed a promotional website for Argosari Village tourism packages together with a population statistics dashboard embedded directly into the site. The goal was to give residents and village administrators a single access point to monitor population data while promoting the village's tourism potential digitally.
